Ejercicio 3 — Formulario alineado con GridLayout
GridLayout es ideal para construir formularios donde las etiquetas y los campos deben estar perfectamente alineados en columnas. En este ejercicio vas a reemplazar el posicionamiento manual por una grilla ordenada.

Creá una ventana con un formulario de contacto que utilice GridLayout para organizar sus campos. El formulario debe contener:

Etiqueta y campo de texto para Nombre
Etiqueta y campo de texto para Apellido
Etiqueta y campo de texto para Teléfono
Etiqueta y campo de texto para Email
Etiqueta y campo de texto para Mensaje
Todos los pares etiqueta-campo deben estar perfectamente alineados en dos columnas. El formulario debe estar en la zona CENTER de un BorderLayout, y en la zona SOUTH debe haber un panel con los botones "Enviar" y "Cancelar".

💡 Tip: el GridLayout asigna el mismo tamaño a todas las celdas. Si el campo de "Mensaje" necesita más espacio, investigá cómo usar JTextArea en lugar de JTextField y cómo envolverlo en un JScrollPane.
